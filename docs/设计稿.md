## 设计判断

1. **拿不到 PCL2 源码工程时，"只改 UI"如何落地**：把逻辑边界收敛成接缝层 `LauncherServices`，UI 只认这一个对象。核心层用等价最小实现先跑通，替换成 PCL 原生模块时界面不动——这样"只改 UI"从口号变成一次可执行的替换（映射表在移植说明 §3）。
2. **核心层不依赖 WPF**：既能在 Linux 沙箱真编译真测试，也顺带保证了 UI 可整体换掉。
3. **下载开关**：默认关闭 + 必须记录一次用户确认，不做静默绕过；只指向 Mojang 官方端点与公开镜像。这是唯一需要"改代码"才能默认放开的地方，正好落在用户要求的"那一行"。
4. **服务器列表不写 servers.dat**：游戏原生列表是 gzip NBT，写坏会毁玩家数据；改用 `--server/--port` 启动参数，行为等价、风险为零。
5. **EasyTier 状态解析按表头取列**：不同版本列顺序变过，绑定列名比按位置切片稳。
6. **测试零 NuGet 依赖**：沙箱与离线机器都不会因还原失败而跑不起来。
