Less setup, more play

游戏的准备工作，
也可以很简单。

从管理常用版本，到整理模组内容、连接好友的世界，把常用操作放进一个连贯的桌面体验。

版本，各自安放

用独立卡片查看和切换已安装版本。Fabric、Forge 等加载器与不同游戏配置，都能更清楚地管理。

模组与整合包，一起整理

搜索并安装 Modrinth 模组或整合包，也支持 LabyMod 客户端。所需加载器和内容各有入口。

和朋友，换种方式联机

提供 EasyTier 陶瓦联机与 Yggdrasil 红石外置登录入口；连接方式和服务端要求请先查看项目说明。

重要开关，清晰可见

Minecraft 本体下载默认关闭，并有单独确认开关。下载来源、运行环境与功能边界都可在文档中了解。

常用设置，随手调整

配置游戏目录、Java 路径和内存参数，选择界面主题，让启动环境更贴合自己的使用习惯。

公开源码，过程透明

项目代码和构建说明托管于 GitHub。想了解实现、反馈问题或参与改进，都可以从仓库开始。

Made for your setup

你的目录、你的 Java，
你来掌控。

把关键环境放到明处：选定游戏目录、配置 Java 和内存，再根据需要启用加载器、模组或联机方式。

  • 面向 Windows 10 / 11 的 WPF 桌面应用
  • .NET 8；运行需要 .NET 8 Desktop Runtime
  • 功能、依赖与已知限制以仓库 README 为准
